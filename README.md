# QualiGuide AI — Local React Migration

This folder contains the migrated multi-file Vite React version of the original single-file Claude Artifact.

## Run locally

```bash
npm install
npm run dev
```

Open the localhost URL shown by Vite.

## Current scope

- Frontend-only educational prototype
- Four simulated roles
- Dashboard, document library, Q&A, NCR assistant, feedback, and Quality Manager review queue
- Rule-based local matching only
- In-memory data resets on refresh
- No backend, external API, real authentication, or cloud service

The original source remains in `reference/ClaudeArtifact.jsx`.
